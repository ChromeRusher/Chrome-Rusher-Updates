# Chrome-Rusher-Updates
Instaladores y metadatos públicos de Chrome Rusher; el código fuente se conserva en un repositorio privado.

Este es el canal de **Windows**. Se conserva esta dirección para mantener las actualizaciones de las instalaciones existentes.

Los canales de [Android](https://github.com/ChromeRusher/Chrome-Rusher-Android-Updates) e [iOS](https://github.com/ChromeRusher/Chrome-Rusher-IOS-Updates) están preparados por separado y todavía no tienen versiones publicadas.
