## Instalación y datos

Las instalaciones Windows 1.0.22 pueden actualizar a 1.15.1 mediante el canal
ordered. Las instalaciones antiguas 3.x conservan el puente latest. Ambos canales
apuntan al mismo instalador y se mantiene la protección contra downgrades.
Se conservan las partidas y la identidad com.chromerusher.arcade.

Android 1.15.1 usa versionCode 15 y la misma firma original. Los APK históricos
conservan sus contadores y contenidos. La primera etapa Android 1.6.0 solo tiene
fuente conservada. Windows se distribuye sin Authenticode comercial por la
autorización del propietario; SECURITY-EXCEPTION.json documenta la edición actual.

Los archivos históricos mantienen su juego original. Se verificaron sus metadatos,
integridad y procedencia; no se repitieron todas las pruebas de jugabilidad sobre
cada motor antiguo. Para jugar se recomienda la versión actual 1.15.1.
