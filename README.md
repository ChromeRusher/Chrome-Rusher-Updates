# Chrome Rusher 1.0.22

La barra de dificultad del encabezado se renueva con iluminación suave, destellos
breves y un indicador que se mueve junto con la carita seleccionada.

La barra ocupa el espacio disponible del menú. Las seis caras, sus etiquetas
y la marca de selección se adaptan al contenedor al redimensionar la ventana.
La preferencia de movimiento reducido y las animaciones desactivadas se respetan.

Se conservan la dificultad global, el desbloqueo de Imposible, los controles de
teclado, las partidas y la selección al cambiar de pestaña. Los otros sistemas
de juego y los servicios online mantienen su funcionamiento.

La actualización sigue la serie ordenada desde 1.0.0. Windows puede actualizar
desde 1.0.21 y mantiene el canal de compatibilidad con instalaciones 3.x. Android
usa versionCode 14 y conserva la firma original. iOS queda como fuente preparada
con versión 1.0.22, sin IPA firmado, según el alcance acordado.

Este repositorio distribuye paquetes compilados y metadatos. El código del juego es privado.
