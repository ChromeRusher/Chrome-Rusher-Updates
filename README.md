# Chrome Rusher 1.15.1

La barra demoníaca conserva el pulido adaptable de la anterior 1.0.22: las
caritas, el indicador y el resaltado se mueven juntos y respetan el movimiento reducido.

Por solicitud del propietario se reclasifica el historial con SemVer según su
alcance real. Las ampliaciones compatibles incrementan MINOR, las correcciones
PATCH y las preparaciones internas se agrupan con su publicación correspondiente.
La serie semántica comienza en 1.0.0 y esta edición corresponde a 1.15.1.

Se conservan los paquetes, etiquetas y enlaces anteriores como referencias de
compatibilidad. La actualización normal de Windows desde 1.0.22 utiliza ordered;
las instalaciones antiguas 3.x conservan su puente. No se pierden partidas ni se
modifican reglas, modos, puntos, demonios o servicios online.

Android utiliza versionCode 15 y la clave original. iOS queda como fuente
preparada, sin IPA firmado, según el alcance acordado.

Este repositorio distribuye paquetes compilados y metadatos. El código del juego es privado.
